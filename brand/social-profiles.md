## Naming rule

- The name is the brand plus what we teach: **Zero Fear Scooty & Bike Training**. It matches the
  website and the logo line, so it is allowed on Google.
- On Google **never** add places or extra keywords to the name (“Best … in Tollygunge”, “Kolkata”,
  “Ladies”). Google treats that as keyword stuffing and can suspend the profile. Keywords go into the
  category, services and description instead.

   (a few days; it may ask for a short video of the signboard/banner, the place and a class).
   Put up a Zero Fear banner first. Don't change the address or phone at the same time.
3. Upload the new profile picture.
4. Replace every bio, about and link with the text above.
5. Remove any old links, highlights or pinned posts that point to another brand.
6. Make one "Welcome to Zero Fear" post with the logo.
7. Send the new Instagram / Facebook links so the website footer can be updated (admin → Contact & numbers).
